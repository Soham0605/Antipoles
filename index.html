Antipode Mathematics

An antipode is the exact opposite point on the Earth's surface. We calculate this using spherical coordinates.

1. Current Coordinates

Latitude (φ): --°

Longitude (λ): --°

2. Latitude (φ) Inversion

The antipodal latitude is simply inverted across the equator.

φanti = -(φ)
φanti = -(--)
φanti = --°

3. Longitude (λ) Shift

The longitude shifts exactly halfway around the globe (180°). We bound the result between -180° and 180°.

if (λ > 0):
  λanti = λ - 180°
else:
  λanti = λ + 180°

λanti = -- ± 180
λanti = --°
